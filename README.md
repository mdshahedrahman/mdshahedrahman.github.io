# Mohammad Shahedur Rahman — Personal Website

Academic and professional website: https://mdshahedrahman.github.io/.

- [Preview locally](LOCAL_PREVIEW.md)
- [Publish with GitHub Pages](DEPLOYMENT.md)
- Edit content in `_pages/`, navigation in `_data/navigation.yml`, and styles in `_sass/`.
- Use `Gemfile.local` and its committed lockfile for both local and production builds.

The current website replaces the former pages and sample collections while preserving repository history. Original master snapshots are kept separately in the local workspace.

Built with Jekyll and [Academic Pages](https://github.com/academicpages/academicpages.github.io), originally forked by Stuart Geiger from the [Minimal Mistakes Jekyll theme](https://mmistakes.github.io/minimal-mistakes/), © 2016 Michael Rose, under the [MIT license](LICENSE). Layout inspiration: S M Ferdous’s academic website. Personal content and assets belong to their respective owners; icon source URLs are recorded in `images/verified-icons/sources.json`.
